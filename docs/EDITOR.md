# Editing the Level in Godot

Open `scenes/main.tscn` to see the whole level. Expand `EditableLevel` to reach nested saved scenes in `scenes/generated/`: `Trail` contains `Ground`, `House`, `Fence`, `Flora`, and `Landmarks`; `House` contains separate floor, roof, stair, cellar, furniture, light, and haunting scenes. The cellar contains a separate morgue scene. You can edit their children in the scene tree or open a subscene directly to work on it. Save the scene you changed before playing. The game applies saved Inspector properties to the matching gameplay nodes at startup, including transforms, meshes, materials, collision shapes, lights, and visibility. Actor rig internals belong to their source assets. You can add ordinary scene nodes under an existing generated parent. Delete matching collision bodies when removing solid props. Gameplay nodes such as doors should be moved or hidden, since their scripts still need to exist.

Select `Main` in `scenes/main.tscn` to edit **World Seed**. The default `-1` chooses a fresh seed each time you click **Randomize / rebuild editable level**. A nonnegative number produces a repeatable layout. The resolved seed is stored in the editable scene so the level you edit matches the level you play.

Rebuilding replaces `scenes/editable_level.scn` and every scene in `scenes/generated/`, including hand edits. Save a copy before regenerating a layout you want to keep. Changes to generator code in `scripts/world/` or `scripts/house/` also require a rebuild so node correspondence remains valid. Terrain height sampling remains procedural; move props, walls, lights, and the player preview for hand placement. The hunter follows its AI after play starts.
