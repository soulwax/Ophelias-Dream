# Found Styloo arrow

Extracted from the CC0 Styloo elf model with `tools/extract_elf_bow.py --arrow`; the source mesh and color texture are retained. The original character pack is not modified. Editable Blender source is in `source/arrow.blend`.

The game places three four-arrow sheaves along the trail. The quiver holds eight. A nocked arrow appears while aiming; fired shafts collide with the world and can be recovered. See `assets/props/bow/README.md` for the bow and combat controls.
