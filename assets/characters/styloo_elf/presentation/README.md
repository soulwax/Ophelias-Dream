# Presentation characters

`mage.glb`, `nain.glb` and `knight.glb` are copied from the owner's central
asset bank, `thecompanycharactersStyloo/glb/`. Styloo's included readme states
that the pack is CC0 and links to <https://styloo.itch.io/>. The upstream files
are kept unchanged; the presentation catalog references these copies directly.

Each GLB contains its own skinned character and compatible `DEF-*` skeleton,
but no embedded animations. The character presentation previews the project
locomotion libraries on these skeletons, including the feminine walk and jog.
These are presentation assets only and do not replace the playable character.
