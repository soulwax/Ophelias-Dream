# Kenney female presentation models

`character-female-a.glb` through `character-female-f.glb` come from Kenney's
Mini Characters 1.0 pack in the owner's central asset bank. The included
`LICENSE.txt` identifies the pack as CC0. The GLBs are kept unchanged and each
contains a rig plus 32 animation clips. The character presentation uses these
embedded clips directly, rather than applying the Styloo animation library.

These six models add a low-poly style alongside the anime-styled Styloo
characters. They are presentation-only assets.
