# Quaternius Animated Women

`woman.glb`, `woman_casual.glb`, `woman_in_dress.glb` and
`woman_in_tank_top.glb` are the four models from Quaternius's Animated Women
Pack, downloaded in GLB format from the [Poly Pizza pack page](https://poly.pizza/bundle/Animated-Women-Pack-HHSKxnk1mY).
The pack is marked CC0 on Poly Pizza and on the [official Quaternius page](https://quaternius.com/packs/animatedwomen.html).

Each GLB contains a 31-joint skinned rig and 11 animations: clapping, death,
idle, jump, punch, run, running jump, sitting, standing, sword slash and walk.
The presentation uses each model's embedded animation player and loops its
idle and locomotion clips. These are presentation models, not replacements for
the playable character.
